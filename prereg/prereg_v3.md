## 1. 决策层设计(冻结)

**门(命题 1 感知)**:对翻转单元 (i,j),声明审计参照 A ∈ {gR, gR2},
门条件 = 读者承诺方向 = 参照 A 的契约读数 gap 符号(即 rank_ref 符号,
rank_ref = 参照 gold 下逐族 pooled Gap_F1)。门拒绝的对一律 hedge。

**旋钮**:门内对继续按 conf ≥ t 承诺(conf = v2 同款:5 种子均值 bootstrap
差分布与承诺符号一致占比;t 由 CP-RCPS 校准,冻结实现 conformal_reader.
calibrate_threshold,自检 4/4 PASS,δ=0.1)。

**信息流(防泄漏声明)**:门与校准只使用 [读者方向(训练契约池,不含 gR/gR2)]
与 [声明的审计参照 A 的读数符号];认证参照 B 的读数不进入门/校准/特征。
fold 1:门用 gR,认证 gR2;fold 2:对称(门用 gR2,认证 gR)。
x2 无 gR2 契约读数 → x2 对在 fold 2 不可判,从 fold 2 排除(fold 1 正常参与,
记数);gR2 读数来自 gr2_registry.json gR2_points(冻结值)+ 7 FAMS
counts_for(golds_gR2)(确定性重算),与 v2 运行逐位一致(断言)。

**同参照错误率的地位(如实声明)**:门内承诺方向 = 参照 A 方向 → 对 A 的
错误率为 0 是门的结构性结果,**不计入任何主张**。v3 的实质保证内容见 J5'。

## 3. 操作点(先验冻结)

- **主操作点 α\* = 0.20**。先验理由(功效计算,非事后选择):
  CP 零错误地板 n ≥ ln(δ)/ln(1−α);α=0.10 → n ≥ 21.9,门内校准折
  (~12 单元)不可达 → α=0.10 在本单元池上结构性不可判(如实报告);
  α=0.20 → n ≥ 10.3,可达。α 网格 {0.02,0.05,0.10,0.20,0.30} 全报告。
- 工作点 hedge 判定取两折保守合并:对每个声明参照 A 的工作点
  (门_A, t*_A)分别计算 J6'/J7',取最不利(覆盖取 min,false-tie 取 max);
  参照 A 下不可判的对(如 gR2 工作点的 x2 对)计入 hedge。

## 4. 判据(先于运行冻结)

- **J5'(保证有效性,主判据)**:α\*=0.20 上两折已实现错误率 ≤ α\*
  (各折门内测试承诺数 ≥5 才可判)。保证语义:**以声明参照 A 为真值的
  承诺集,对参照 B(gold 版本扰动)的迁移错误率 ≤ α\***。
- **J6'(覆盖)**:α\* 工作点翻转覆盖(hedge)≥ AER−1(=19,v2 同基线)。
- **J7'(代价)**:α\* 工作点 false-tie ≤ min(固定基线 gD_native/AER_corpus
  于 registry v3)= 65(v2 同基线)。
