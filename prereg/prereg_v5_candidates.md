# prereg v5 候选议程(2026-11-15 起草;DRAFT——非预注册,纯候选清单)

状态:候选议程草稿。来源 = prereg v4 确认周期收官后的方法不足实测账单
(合并稿 Discussion limitations + 失败谱系 + 三抓约定错位的执行教训)。
**本文件不是预注册**:任何条目进入确认运行前,须单独起草 prereg v5 判据、
经作者审定 FROZEN 并满足止损门;本文件仅圈定候选方向与成本,不构成判据。

---

## 候选 1:池增长至 K≥44(拆样本 census 证书解锁)

- **不足**:census 证书是池描述口径;拆样本(前瞻)证书地板翻倍
  (T1 需 n≥44),现存 24 模型不足。
- **路径**:x2 族内 +4 模型(已达 24);跨族增长=每个新架构 ×2 臂
  ×2 比 ×2 种子 ≈ 8 run/族,atlop 系 1.5-3 GPU-h/run。
  目标 = 训练侧计数 K≥44 族或 x2 内 n≥44(二选一决定证书语义)。
- **解锁**:split-sample 前瞻证书(T1:44 模型零坏容忍校准/验证对半);
  weighted conformal 的 n_eff 地板(修正案:C5w 的 margin 需 n≥22 校准)。
- **成本**:x2 内 +20 run ≈ 1.5 GPU-天;跨族 20 族 ≈ 2-4 周 GPU。
- **风险**:新模型健康门失败率(e50 前例零失败;DocuNet 类退化除外);
  增长后 census_n 语义变化须修正案预登记。

## 候选 2:exact weighted-distribution 界(理论任务)

- **不足**:C5w pilot 证明 weighted conformal 估计量 sound(48% 可加权)
  但 Hoeffding 边距在折尺寸 ~13 永不触发(需 n≥22 零错地板)。
- **路径**:权重取少数离散值(cell 多重性)→ 加权和的**精确分布**
  可由卷积/枚举计算,替代 Hoeffding 松界;有效性命题(加权 iid 下
  精确覆盖)3 行证明 + MC 验证。
- **解锁**:加权证书在折尺寸 13-26 可行化 → MP 级覆盖(9.6)与
  FS 级有效性(0.035)同时成立 = 方法论文升格的真候选。
- **成本**:理论 + 实现 ≈ 1-2 周;无 GPU。
- **风险**:精确界若仍不可行(小 n 的离散性),候选判死——判据须预声明。

## 候选 3:Declare 步"约定清单"(协议修正,最便宜)

- **不足**:Phase 2/3 三抓约定错位(通用 CNT→p3io.CNT / 扁平 vs
  per_doc 代际 / own-gold vs 统一 gD)——每次改变数字,均为 Declare
  未显式声明的提取约定。
- **路径**:协议的 Declare 步增加**约定清单**义务:提取布局(CNT 序)、
  文件代际(子目录/扁平)、金标指派(own vs 统一)、变体键名
  (cal_sigmoid_multilabel)——每项随读数表发布。
- **解锁**:不再有"约定漂移改数字";Phase 2 类返工归零。
- **成本**:一次修正案 + 读数表 schema 补字段。**建议 v5 必选**。

## 候选 4:第二测试床复制(地图形状验证)

- **不足**:工作证书 DocRE-scoped(limitation i);协议领域一般性
  缺第二实例。
- **路径**:候选域按适用 2×2 表预筛——选"可交换+翻转有代价"格
  (与 DocRE 同格)而非 TACRED(不可交换)/WMT(零翻转)格;
  例:NLG judge 生态(judge 身份=契约轴,jung2024trust 的测试床
  反向复用)。
- **解锁**:地图形状跨域复制 = 协议领域一般性的实证;
  预期结果 = 定律与层级序复制(具体数值域特异)。
- **成本**:新域数据+模型+审计 ≈ 3-6 周。
- **风险**:结果可预期(定律保证形状复制)——价值在复制不在发现,
  定位须诚实(验证件非新发现)。

## 候选 5:judge-轴扩展(LLM-judge 生态,远期)

- **不足**:方法未在 judge-based 评测上实例化;而 judge 身份
  (哪个 LLM 当裁判)是天然的契约轴,与 jung2024trust 的对象衔接。
- **路径**:judge 生态的 Declare→Measure(candidates=被评对象,
  contracts=judge×prompt×模板);与 Part 3 的 map 对接。
- **成本**:新生态全量(数据/模型/审计)≈ 6-8 周;新失败模式
  (judge 偏置轴)未探测。
- **风险**:与 jung2024trust 的区分已在判据层成立(scope 步),
  但审稿人可能仍要求正面比较;单独立项评估。

## 优先级建议(成本×解锁×风险)

1. **候选 3(约定清单)**:零成本协议修正,建议 v5 必选;
2. **候选 2(精确界)**:无 GPU、判据可预声明、失败也有报告价值;
3. **候选 1(池增长)**:GPU 大头,依作者算力窗口(与 P2 线协调);
4. **候选 4(第二测试床)**:复制价值,窗口空闲再排;
5. **候选 5(judge 轴)**:远期,单独立项。

## 纪律提醒

  (flips≥35 / census_n≥22 / 约定清单已入 Declare)→ 方可运行;
